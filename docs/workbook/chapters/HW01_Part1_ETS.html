16 Overview

Homework 1 comes in two parts. Part 1 (this document) covers exponential smoothing and is due before class in Week 2 — it uses only material from Lecture 1. Part 2 covers ARIMA, VAR, and method comparison, and is due before class in Week 3, after Lecture 2.

Each part has its own context prompt, its own prompt budget, and its own submission. Do not start Part 2 until Part 1 is submitted.

Exponential smoothing is a workhorse of operational forecasting in retail and supply chain: interpretable, cheap to fit, and hard to beat at scale. Working through real store-level sales data, you will see how the choice of smoothing model and the rigor of evaluation translate directly into business decisions.

Learning objectives. By the end of Part 1 you will be able to:

  • Read a retail time series plot for trend, seasonality, and business-driven irregularity
  • Apply Simple Exponential Smoothing, Holt’s linear trend model, and Holt-Winters to seasonal weekly data
  • Interpret the smoothing parameter \(\alpha\) in business terms
  • Compare competing models on a held-out test set using RMSE and MAE, against a benchmark

17 Dataset

This course runs on the M5 / Walmart dataset — the spine described in ECON8310_Datasets.md. It covers daily unit sales for Walmart stores across California, Texas, and Wisconsin from 29 January 2011 to 22 May 2016, and it was the data for the M5 forecasting competition.

You will work with the prepared weekly file, data/processed/m5_weekly.csv: 30 series (10 stores × 3 product categories), 277 weeks each, with average price, SNAP benefit days, and event-day counts alongside the unit sales.

If the file does not exist, run python scripts/prep_m5.py once first — it will tell you where to get the raw download.

import pandas as pd

from pathlib import Path

def data_path(name):
    """Find the processed data file whether you render from the repo root or from
    this file's own folder."""
    for base in (Path.cwd(), *Path.cwd().parents):
        p = base / "data" / "processed" / name

            return p

        "Run `python scripts/prep_m5.py` from the repository root first."

# Store CA_1, FOODS category, for the univariate models in Part 1

19.2 Q2 — Exponential Smoothing Models

(Suggested prompts: 2)

Hold out the final 52 weeks as a test set. Fit the three models below on the training portion, forecast across the test period, and compute RMSE and MAE for each.

  • Simple Exponential Smoothing (SES)
  • Holt’s linear trend model
  • Holt-Winters (additive seasonality, period = 52)

Also compute the same two metrics for a seasonal naive benchmark — this week last year — so you can tell whether any of the three models is earning its complexity. Present all four rows in one summary table.

Why a 52-week test set works here

Holt-Winters must estimate a seasonal index for each of the 52 weeks in a year, and it needs at least two complete cycles — \(2m = 104\) observations — before it can initialize them. This is the \(2m\) rule from Lecture 1.

Each series has 277 weeks. Holding out 52 still leaves 225 for training, comfortably above the threshold, and a one-year holdout is the horizon a demand planner actually cares about. The assertion below makes the constraint explicit rather than letting it fail deep inside statsmodels.

N_TEST = 52                                   # final year held out
train, test = ca1.iloc[:-N_TEST], ca1.iloc[-N_TEST:]

SEASONAL_PERIOD = 52
assert len(train) >= 2 * SEASONAL_PERIOD, (
    f"Training set has {len(train)} weeks but Holt-Winters with period "
    f"{SEASONAL_PERIOD} needs at least {2 * SEASONAL_PERIOD}. "
    f"Reduce N_TEST."
)
print(f"train: {len(train)} weeks   test: {len(test)} weeks")

# Fit SES, Holt, and Holt-Winters; add a seasonal naive benchmark;
# compute RMSE and MAE for all four

Your response: Which model performs best, and does it beat the seasonal naive benchmark? This series trends upward over the sample — explain what that implies for SES specifically, given that SES produces a flat forecast. Then interpret the estimated \(\alpha\): what does its value say about how quickly CA_1 food sales respond to recent weeks, and what would you tell a demand planner who wanted to know how much weight the model puts on last week?

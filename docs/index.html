ECON 8310: Business Forecasting

University of Nebraska at Omaha · Department of Economics
Fall 2026

Forecasting tools and applications for business settings. The first half of the course covers traditional econometric forecasting; the second half turns to predictive analytics and machine learning. Everything is implemented in Python.

BookUsed for

Before the first lab

Every lab and homework in this course reads from prepared data files that are not in the repository. Run these three commands once, from the repository root, before Week 1:

python scripts/prep_m5.py            # M5 / Walmart — the course spine
python scripts/prep_fred.py          # FRED macro series — Lecture 2
python scripts/prep_electricity.py   # hourly electricity demand — Lecture 3

Each downloads from a public source, needs no login or API key, and writes to data/processed/. Once they have run, nothing in this course needs the network again.

macOS users: one extra step before Week 5

XGBoost will not import on macOS without the OpenMP runtime. Install it once with brew install libomp, then pip install xgboost. Do this before Lab 5 rather than during it.

You will also need: jupyter, pandas, numpy, matplotlib, statsmodels, scikit-learn, prophet, pygam, xgboost, torch, pymc, and arviz. jupyter is not optional — Quarto runs your Python through a Jupyter kernel. Assignment submission, the Codex workflow, and the prompt log live in the course environment repository.

Each assignment has a prompt budget

Every assignment carries a fixed number of Codex prompts and an initial context prompt that does not count against it. You submit a PROMPT_LOG.jsonl alongside your rendered work. The budget is a design feature, not a restriction — it forces you to decide what is worth asking.
